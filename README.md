# Hykrox — Creative Designers

A responsive React + TypeScript landing page inspired by the supplied UI challenge design. It uses plain CSS for layout and styling.

## Development

```sh
npm install
npm run dev
```

## Validation and production build

```sh
npm run lint
npm run build
```

The production-ready static site is generated in `dist/`. Deploy that directory to a static host such as GitHub Pages or Firebase Hosting. The portrait images are local crops from the supplied reference design.
